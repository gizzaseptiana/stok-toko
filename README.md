# 👔 Calvin Klein - Stok Pakaian

Aplikasi web satu halaman (SPA) untuk mengelola stok pakaian brand Calvin Klein.

---

## ✨ Fitur Aplikasi

| Fitur | Method HTTP |
|-------|-------------|
| Lihat daftar pakaian | GET |
| Tambah pakaian baru | POST |
| Edit pakaian | PUT |
| Hapus pakaian | DELETE |

---

## 📂 Struktur Project
stok-toko/
├── index.html
├── style.css
├── script.js
└── README.md


---

## 🚀 Cara Membuka Aplikasi

### Cara 1: Langsung Buka File
1. Download atau clone repository ini
2. Buka folder `stok-toko`
3. Klik dua kali file `index.html`
4. Aplikasi akan terbuka di browser default Anda

### Cara 2: Menggunakan Live Server
1. Buka folder project di **VS Code**
2. Install ekstensi **Live Server**
3. Klik kanan file `index.html`
4. Pilih **Open with Live Server**

---

## 📝 Cara Penggunaan

**Tambah Pakaian:**
- Isi nama, pilih kategori, isi harga → klik Tambah Pakaian

**Edit Pakaian:**
- Klik Edit → ubah data → klik Simpan Perubahan

**Hapus Pakaian:**
- Klik Hapus → konfirmasi Ya → pakaian terhapus
